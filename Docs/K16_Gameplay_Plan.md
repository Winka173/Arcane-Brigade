# K16 character craft and build identity

1. Redraw the three overpainted K14 recruits, Lantern Knight and Wax Admiral in
   consistent bold-ink, restrained cel-shaded style; preserve identities and no arms.
2. Give each a twelve-pose state-driven set: idle/blink, four-step walk,
   anticipation, release/follow-through and recovery/expression.
3. Fix nearest-side melee engagement, windup target retention/aim, large-target
   reach, bounded pursuit and dead-target reacquisition without resetting timers.
4. Add real tier-dependent yo-yo control, sewing links and projector convergence,
   plus distinct magnet/hammer/ribbon payoffs; nonrecursive secondary causes.

Regression, authored encounter diagnostics, native Windows captures and build gates
before main. Audio/UI styling are not redesigned. First wave, movement-only controls,
recruitment quotas, full heal and run-only stats remain unchanged. Full roster redraw,
new boss encounter design and maximum-load/device gates are not this delivery.
